Sesión 0 — Documentación e Instalación

Objetivo

Introducir al estudiante en la importancia de la documentación técnica y los pasos fundamentales para la instalación de entornos de desarrollo y herramientas necesarias para la materia.

¿Por qué es importante la documentación?

  • Facilita la comprensión y el mantenimiento de proyectos.
  • Permite la colaboración efectiva entre desarrolladores.
  • Reduce errores y acelera la resolución de problemas.
  • Ejemplo: Manuales de usuario, guías de instalación, comentarios en el código.
Recordá
Documentar no es un paso extra: es parte del trabajo. Un buen README o una buena guía de instalación le ahorran horas de confusión al próximo desarrollador (que muchas veces sos vos mismo, unos meses después).

Paso a paso: extensión de Python en VSC
Una vez instalado Python, Node.js y VS Code, en el mismo Visual Studio Code hacé click en el botón de Extensiones (columna de iconos del lado izquierdo). Escribí python y solo instalá las extensiones firmadas por Microsoft: esto va a permitir ejecutar código Python directamente desde el editor.

Buenas Prácticas de Instalación

  • Leer siempre la documentación oficial antes de instalar.
  • Verificar requisitos del sistema.
  • Preferir instaladores oficiales y evitar fuentes desconocidas.
  • Ejecutar pruebas básicas tras la instalación para confirmar el funcionamiento.
