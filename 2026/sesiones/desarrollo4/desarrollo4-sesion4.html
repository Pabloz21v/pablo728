Sesión 4 — CSS: Grillas con Grid Layout

Flexbox nos ordena en una dimensión (fila o columna). Hoy damos el salto a dos dimensiones a la vez con CSS Grid: filas y columnas simultáneas, áreas de rejilla con nombre propio, y diseño adaptativo nativo sin escribir un solo @media.

Objetivos de aprendizaje

Al finalizar esta sesión, vas a poder:

  • Explicar la diferencia entre un layout de una dimensión (Flexbox) y uno de dos dimensiones (Grid), y decidir cuándo usar cada uno.
  • Definir una rejilla con grid-template-columns y grid-template-rows, usando unidades fijas, fr y funciones como repeat() y minmax().
  • Ubicar ítems en celdas específicas con grid-column y grid-row.
  • Diseñar layouts completos usando áreas de rejilla nombradas con grid-template-areas y grid-area.
  • Construir un diseño adaptativo nativo con repeat(auto-fit, minmax(...)), sin necesidad de @media queries para la grilla de productos.
  • Maquetar la estructura completa de la página del E-commerce (header, nav, catálogo, aside, footer) con Grid.

Flexbox vs. Grid: ¿cuándo uso cada uno?

En la Sesión 3 usamos Flexbox para acomodar las tarjetas de producto en una fila que se reacomoda sola. Grid no reemplaza a Flexbox: son complementarios y de hecho se combinan todo el tiempo en un mismo proyecto.

FlexboxCSS Grid
DimensiónUna sola: fila o columnaDos a la vez: filas y columnas simultáneas
Ideal paraMenús, barras de botones, centrar contenido, una fila de tarjetasLayouts de página completos, grillas de productos con muchas filas y columnas
ControlEl contenido "empuja" el tamaño de cada ítemSe define la estructura de la rejilla primero, y los ítems se acomodan dentro
Ejemplo en el proyectoLos botones dentro de una tarjeta de productoLa estructura general de la página: header + nav + catálogo + aside + footer
Analogía
Flexbox es como acomodar una fila de personas en el cine. CSS Grid es como dibujar el plano completo de la sala: primero trazás filas y columnas de butacas (la rejilla), y después decidís en qué butaca exacta (fila X, columna Y) se sienta cada persona. Un plano de sala puede además tener, adentro de una butaca especial (palco), una fila de asientos ordenada con Flexbox: por eso se combinan.

La lógica de Grid: filas y columnas

Todo empieza igual que con Flexbox: hay que activarlo en un contenedor con display: grid;. A partir de ahí, en lugar de un solo eje, definimos una grilla completa con dos propiedades clave:

PropiedadFunción
display: grid;Activa Grid en el contenedor. Sin esto, ninguna otra propiedad de Grid tiene efecto.
grid-template-columnsDefine cuántas columnas tiene la rejilla y qué ancho tiene cada una.
grid-template-rowsDefine cuántas filas tiene la rejilla y qué alto tiene cada una.
gapEspacio uniforme entre filas y columnas (equivalente a row-gap + column-gap).
ejemplo-grid-basico.css 
.contenedor {
    display: grid;

    /* 3 columnas: la primera de 150px fijos,
       la segunda ocupa el doble de espacio libre que la tercera */
    grid-template-columns: 150px 2fr 1fr;

    /* 2 filas: la primera de 80px fijos, la segunda automática
       (se ajusta a lo que el contenido necesite) */
    grid-template-rows: 80px auto;

    gap: 16px;
}
Cada "palabra" es una columna/fila
En grid-template-columns: 150px 2fr 1fr; hay 3 valores separados por espacios → eso significa 3 columnas. Si necesitás 5 columnas iguales, en vez de escribir 1fr 1fr 1fr 1fr 1fr podés abreviar con repeat(5, 1fr) (lo vemos en detalle más abajo).

La unidad fr y la función minmax()

fr significa "fracción del espacio libre disponible". Es la unidad más usada en Grid porque permite proporciones flexibles sin calcular porcentajes a mano.

Código¿Qué significa?
grid-template-columns: 1fr 1fr;2 columnas, cada una con el mismo espacio disponible (50% y 50%).
grid-template-columns: 2fr 1fr;2 columnas: la primera ocupa el doble de espacio que la segunda (aprox. 66% y 33%).
grid-template-columns: 200px 1fr;La primera columna es fija (200px); la segunda ocupa todo el resto del espacio libre.
repeat(3, 1fr)Abreviación de 1fr 1fr 1fr: repite el patrón 3 veces.
minmax(120px, 1fr)La columna nunca es más chica que 120px, pero puede crecer hasta ocupar 1fr (el espacio libre disponible).
Analogía
fr es como repartir una pizza entre amigos según "porciones de hambre" en vez de tamaños fijos: si decís 2fr 1fr, es como decir "a este amigo dale el doble de porción que al otro", sin importar el tamaño total de la pizza. minmax(120px, 1fr) agrega una condición: "esta porción nunca puede ser más chica que un bocado mínimo de 120px, pero después sí puede crecer todo lo que el hambre disponible permita."

Posicionar ítems específicos en la rejilla

Por defecto, Grid ubica cada ítem en la siguiente celda libre, en orden. Pero podemos decirle explícitamente a un ítem en qué línea empieza y en cuál termina, incluso haciendo que ocupe varias celdas (como combinar celdas en una tabla de Excel).

Propiedad (en el ítem)Función
grid-column: 1 / 3;El ítem ocupa desde la línea 1 hasta la línea 3 de columnas (es decir, abarca 2 columnas).
grid-row: 1 / 3;El ítem ocupa desde la línea 1 hasta la línea 3 de filas (abarca 2 filas).
grid-column: span 2;Forma abreviada: "ocupá 2 columnas a partir de donde estés", sin especificar números de línea exactos.
Ojo con la numeración de líneas
Las líneas de la rejilla se numeran empezando en 1, y son las líneas divisorias entre columnas, no las columnas en sí. Una rejilla de 3 columnas tiene 4 líneas (antes de la 1.ª, entre la 1.ª y 2.ª, entre la 2.ª y 3.ª, y después de la 3.ª). Por eso grid-column: 1 / 3; abarca las columnas 1 y 2, no "las columnas 1 a 3".
ejemplo-posicionamiento.css 
.contenedor {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: repeat(2, 150px);
    gap: 12px;
}

/* Este producto destacado ocupa 2 columnas de ancho */
.producto-destacado {
    grid-column: span 2; /* abarca 2 columnas a partir de su posición */
}

/* Este banner ocupa toda la fila (las 3 columnas) */
.banner-promocional {
    grid-column: 1 / 4; /* desde la línea 1 hasta la línea 4: las 3 columnas completas */
}

Áreas de rejilla con nombre (grid-template-areas)

En vez de contar líneas y columnas a mano, Grid permite dibujar el layout con nombres, literalmente como un mapa de texto. Es la forma más legible y más usada en proyectos reales para maquetar una página completa.

ejemplo-areas.css 
.pagina {
    display: grid;
    grid-template-columns: 200px 1fr 200px;
    grid-template-rows: auto 1fr auto;

    /* Cada palabra entre comillas es una CELDA.
       Repetir el mismo nombre en celdas contiguas
       hace que esa área "ocupe" todas esas celdas. */
    grid-template-areas:
        "header header header"
        "nav    main   aside"
        "footer footer footer";
}

/* Cada elemento hijo se asigna a un área por su NOMBRE */
header  { grid-area: header; }
nav     { grid-area: nav; }
main    { grid-area: main; }
aside   { grid-area: aside; }
footer  { grid-area: footer; }
Analogía
grid-template-areas es como dibujar el plano de una casa con fibrón directamente en el CSS: escribís "cocina cocina living" / "living living living" / "baño dormitorio dormitorio" y el navegador construye la casa exactamente como la dibujaste. Cada palabra repetida en celdas contiguas se "fusiona" en una sola habitación más grande.
Regla estricta del "mapa"
Todas las filas de grid-template-areas deben tener la misma cantidad de palabras (columnas), y cada nombre debe formar siempre un rectángulo completo (no se pueden repetir nombres en celdas que no sean contiguas, ni dejar "agujeros" con forma de L). Si te equivocás, el navegador tira un error de sintaxis en la consola y esa regla completa se ignora.

Demo interactiva: el mismo HTML, dos layouts distintos

Este es el "truco de magia" más importante de Grid: con el mismo HTML (header, nav, main, aside, footer, en ese orden), solo cambiando el CSS de grid-template-areas logramos layouts totalmente distintos para escritorio y para celular. Probá los dos botones:

.contenedor { display: grid; grid-template-columns: 200px 1fr 200px; grid-template-rows: auto 1fr auto; grid-template-areas: "header header header" "nav main aside" "footer footer footer"; }
La clave está en el CSS, no en el HTML
Fijate que el orden de las etiquetas en el HTML nunca cambió: solo redefinimos qué área ocupa cada una según el ancho de pantalla, típicamente combinando esto con un @media que reescribe grid-template-columns, grid-template-rows y grid-template-areas para pantallas chicas.

Diseño adaptativo nativo: repeat(auto-fit, minmax(...))

La combinación más poderosa de Grid para grillas de productos es esta fórmula, que logra un catálogo responsivo sin escribir un solo @media:

ejemplo-adaptativo.css 
.catalogo-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
    gap: 20px;
}

Desglosemos exactamente qué hace cada parte:

Parte¿Qué hace?
repeat(...)Repite el patrón que le sigue tantas veces como sea necesario.
auto-fitLe dice al navegador: "calculá vos solo cuántas columnas entran" según el ancho disponible.
minmax(220px, 1fr)Cada columna nunca es más chica que 220px (así ninguna tarjeta queda aplastada), pero se estira con 1fr para repartir el espacio libre restante entre las columnas que sí entraron.
Analogía
Es como acomodar sillas de un aula sin medir con regla: le decís al conserje "poné sillas de al menos 220px de ancho cada una, tantas como entren en el salón, y si sobra espacio, repartilo en partes iguales entre todas". En una pantalla grande entran 4 sillas por fila; en un celular, el mismo criterio hace que entre 1 sola por fila, sin que nadie tenga que ir a recalcular nada.
auto-fit vs. auto-fill
auto-fit "colapsa" las columnas vacías y estira las que sí tienen contenido para llenar el espacio. auto-fill mantiene los espacios de columnas vacías visibles (útil si necesitás que las tarjetas no se agranden aunque haya lugar). Para catálogos de productos, auto-fit es casi siempre la opción correcta.

Continuidad del proyecto
Notá el "Grid dentro de Grid": la página completa es un contenedor Grid (#pagina), y adentro, el catálogo de productos es otro contenedor Grid independiente (.catalogo-grid). Anidar grids así es completamente normal y es la forma profesional de maquetar sitios complejos.

Detectá el error: código para corregir en VSC

Copiá estos fragmentos en VSC y usá el Inspector (F12) → pestaña Elements → panel "Layout" (muestra visualmente las líneas de la rejilla) y la Console para encontrar los errores.

Con errores

Ejercicio 1 — Columnas, filas y unidad fr

buggy-7.css 
.catalogo-grid {
  grid-template-columns: 1fr 1fr 1fr;
  gap: 20px;
}

.producto-destacado {
  grid-column: 1 / 1;
}

🔎 Las tarjetas no forman ninguna grilla, y la tarjeta destacada no se agranda como se espera. Encontrá 2 problemas.

Ver solución y explicación
  1. Al contenedor .catalogo-grid le falta display: grid;. Sin esa línea, grid-template-columns y gap no tienen ningún efecto (el navegador sigue tratando al contenedor como un bloque normal).
  2. grid-column: 1 / 1; le dice a la tarjeta que empiece y termine en la misma línea (línea 1 a línea 1), lo cual da un ancho de cero (visualmente el navegador "ignora" ese rango inválido y la tarjeta ocupa su tamaño mínimo). Para que abarque 2 columnas, debería ser grid-column: 1 / 3; o, más simple, grid-column: span 2;.

Tip de debugging: en el Inspector, seleccioná el contenedor y activá el ícono de grilla (junto al nombre del elemento en el panel Elements): si el contenedor no tiene display: grid activo, ese ícono ni aparece.

Con errores

Ejercicio 2 — grid-template-areas mal formado

buggy-8.css 
#pagina {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-areas:
    "header header header"
    "nav main"
    "footer footer footer";
}

header { grid-area: header; }
nav    { grid-area: navegacion; }
main   { grid-area: main; }
footer { grid-area: footer; }

🔎 La consola del navegador muestra un warning y el layout no se ve como se espera. Encontrá 2 problemas.

Ver solución y explicación
  1. La segunda fila del "mapa" ("nav main") tiene 2 palabras, pero la primera y la tercera fila tienen 3. Todas las filas de grid-template-areas deben tener la misma cantidad de columnas: debería ser "nav main main" o similar, respetando las 3 columnas definidas en grid-template-columns.
  2. El selector nav usa grid-area: navegacion;, pero en el "mapa" de grid-template-areas el nombre usado es nav. Los nombres deben coincidir exactamente; si no coinciden, ese elemento no se ubica en ninguna área y el navegador lo posiciona por defecto, rompiendo el diseño.

Tip de debugging: abrí la Console del Inspector: los errores de grid-template-areas mal formado se reportan ahí como "Invalid property value" o similar, señalando la línea exacta del CSS.
