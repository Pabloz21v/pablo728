Ingeniería inversa de un CRUD
y consumo de un JSON propio

Te damos un mini ecommerce funcionando (150 líneas de HTML + CSS + JavaScript puro, sin frameworks). Tu trabajo es desarmarlo, entenderlo y volver a armarlo en una página propia, con estética a elección, que implemente CRUD completo y consuma el JSON que vos mismo armaste.

Al final de esta página está el código fuente 100% disponible para copiar y descargar, más la guía de defensa oral para aprobar la materia.

Objetivos de aprendizaje

Al finalizar este TP vas a poder:

  • Leer código ajeno de principio a fin e identificar sus partes: datos (JSON), lógica (CRUD) y presentación (DOM + CSS).
  • Explicar qué son las operaciones CRUD y en qué línea de código vive cada una.
  • Armar tu propio JSON y consumirlo con JavaScript.
  • Explicar cómo esos datos se transforman en elementos visibles de la página usando la API del DOM (createElement, textContent, appendChild).
  • Justificar con criterio propio la elección de CSS nativo, Bootstrap o Tailwind para tu estética.
  • Defender oralmente tu página: mostrar el CRUD funcionando y responder cómo viaja un dato desde el JSON hasta la pantalla.

3. Reconstruí el CRUD

Con en HTML y CSS de tu web incoporar: agregar (C), listar (R), editar (U) y eliminar (D).

4. Defendé

Mostrá el CRUD funcionando y explicá el recorrido JSON → JavaScript → DOM con tu codigo.

¿Qué es hacer ingeniería inversa?

Programar normalmente es ir de la idea al código. La ingeniería inversa va al revés: te dan el código terminado y tenés que reconstruir la idea que hay detrás. No es "adivinar", es un procedimiento ordenado.

El método en 5 pasos (usalo como guion)

Paso Qué hacés Dónde se ve en nuestro archivo
1. Inventario Listás las partes sin leer la lógica: <style>, <body>, <script>. Tres bloques bien separados en el archivo.
2. Datos Buscás el JSON / array: son los datos del sistema. Constante productosJSON (4 objetos).
3. Lógica Buscás las funciones y agrupás por responsabilidad. Control del formulario, CRUD, eventos.
4. Flujo Seguís un dato desde que se guarda hasta que se ve. crearProducto() → leerProductos() → tarjeta.
5. Rearmado Lo reconstruís con tus datos, tu JSON y tu diseño. Es el TP que entregás.
